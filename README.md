# MAVIS Android

MAVIS is starting as a native Android companion app. Voice is intentionally out of scope for the first build; the first version focuses on typed chat, phone context, memory scaffolding, and simple actions.

## Current Build

- Kotlin + Jetpack Compose Android app
- Typed chat screen
- Local placeholder replies
- Battery status card
- Calendar shortcut

## Next Modules

1. Connect chat to the existing MAVIS backend API.
2. Add local memory storage with Room or DataStore.
3. Add calendar read/write permissions.
4. Add reminders.
5. Add notification listener permission and notification summaries.
6. Add desktop bridge commands.

## Open In Android Studio

1. Install Android Studio.
2. Open this folder: `C:\Users\mahee\OneDrive\Documents\Mavis`.
3. Let Gradle sync.
4. Connect your Android phone with USB debugging enabled.
5. Press Run.

The first Gradle sync will download Android dependencies.
